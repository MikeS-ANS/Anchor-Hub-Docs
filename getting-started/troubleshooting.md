# Troubleshooting

Quick fixes for the problems people run into most. If none of these help, use **Request Support** at the top of the Help screen in the Hub. It sends a message straight to your admin.

## A tool won't load or shows an error

Close Anchor Hub from the tray icon and open it again. Most sign-in errors clear on the next sign-in. If a tool that writes to Autotask says it needs your personal key, add it under **Settings → Autotask**.

## I can't see a tool in the sidebar

Which tools you see depends on your role and any individual grants, both managed on the **Access Management** screen. Ask an Access Admin to check your roles there. If you have no role and no individual grant yet, you'll see a holding screen instead of the sidebar until an admin assigns you one.

## Contract Renewals is showing project contracts

Contract Renewals leaves out contracts whose Contract Category is named "Project" in Autotask. If a project contract uses a category with a different name, it can still appear. It's safe to ignore.

## An update is available but won't install

Click **Check for updates** on the Home page to try again. If it still fails, use the **download** button at the top right of the Help screen to get the latest installer, and run it over your existing installation. Your settings are kept.

## The Help Center won't load inside the Hub

The Help Center needs an internet connection. Check you're online and click **Try again**. You can also click **Open in browser** to read the same pages in your web browser.
