# v4.9.0 — Tool Inventory updates the service plan calculators

Released 7 October 2026.

## Tool counts go straight into the calculators

Each client's Service Plan Pricing Calculator in SharePoint has a **Units** column for the tools we run for them: Datto RMM, Managed Antivirus, PAM, Splashtop and the rest. Until now someone typed those numbers in by hand every month. Tool Inventory now does it.

The new **Calculators** tab (Hub admins only) previews every Units cell that would change for every client, before and after, with an **Open** link to each workbook. Untick anyone you want to leave alone, then press **Confirm** once. The Hub then:

- re-reads each calculator first and writes only the cells that still differ;
- reads every cell back after writing it;
- leaves a dated note in the sheet and a line on a **Hub Change Log** tab in the workbook.

The Hub only touches the Units cells. It never reads, stores or shows a price. A calculator it can't safely update is listed with the reason, so it can be tidied up in SharePoint. That covers a folder with two calculators, an unusual file name, or a layout that has moved.

## Summary emails

A **Digest emails** card on the same tab holds a shared list of people who get an email when an update finishes. The email covers what was written, what failed or was skipped, and what was already up to date, with a link to each workbook. There is also an optional monthly "what will change" preview email, and **Send preview now** for an immediate copy.

## The monthly update runs by itself

With the automatic switch on (it is), the first Hub admin to have the Hub open after 7:00 am once the month's snapshot is in runs the whole update for everyone, exactly as Confirm would. It runs once per month across every machine; the others see it has already run and do nothing. The summary email arrives marked *updated automatically*. Any client that needs a sheet chosen by a person is listed for a quick pick instead of being guessed. The first automatic update ran on 7 October 2026 and wrote September's counts.

## Splashtop Pro is counted

Splashtop has no way for the Hub to read its numbers directly, so Tool Inventory has a new **Imports** tab. Upload Splashtop's own computer-list export there, and the computers in each Splashtop group become that client's Splashtop Pro count (Splashtop's Default Group is never counted). The file is saved to SharePoint first. The newest upload feeds every later month, and a month already taken never changes.

See [Tool Inventory](../tool-guides/tool-inventory.md) for the details. The calculator updates and the Splashtop import were both Mike Stewart's idea.
