# v3.3.1 — Who's Using the App

## New

**Installs tab in Settings** (`hub.admin` only) — see everyone who's launched the Hub: name, machine, app version, and when they were last (and first) seen. Sorted most-recent-first, with a Refresh button.

This surfaces telemetry the app has quietly written to Azure SQL on every launch since the Sprint 2 backend migration — nothing in the UI ever read it back until now.

## Also in this release

Closed a gap on the backend found while wiring this up: the `GET /installs` API route had no role restriction at all. It now requires `hub.admin`, matching every other admin-only route in the Functions API.

See [Roadmap](../getting-started/roadmap.md) for where this sits alongside the rest of the Hub.
