# v3.10.0 — Duo Invoice Processor

**Released:** August 2026

## What's New

### Duo Invoice Processor

A new tool in the invoice-processor family, alongside Pax8, Kaseya, BlackPoint, and Cytracom — this one reconciles ANS's Cisco Duo MFA licensing. Duo has no billing API; ANS gets a flat monthly CSV export instead of a PDF, so there's no PDF parsing involved at all, just a straightforward read of the file's own columns (`Parent, Sub_Account, Account_Id, Number_of_Users, Edition, Date, Price, Cost`).

**Loading a CSV**

- Drag and drop the file, browse for one, or pick a previously-archived file from SharePoint (`ANSVendors/DUO`) through a two-step **Year → File** picker, both sorted newest first
- Since Duo's own filenames don't carry a date, each file in the picker is labeled by its actual billing month — read out of the CSV itself the first time that file is opened, then remembered locally so it doesn't have to be re-read on every app restart
- A locally-supplied file can be archived to SharePoint on the way through, the same as Cytracom

**Reviewing**

- Per-client, per-edition diff: invoice seat count vs. current Autotask contract quantity, for both **Duo Essentials** and **Duo Premier**
- Client matching goes through the Hub Company Directory, now with Duo as its own mapped platform. Matching prefers Duo's own stable account ID over the sub-account's display name, so a client renaming their Duo account doesn't break an existing mapping
- ANS's own internal/test sub-accounts ("Anchor Network Solutions," "Test account," "Anchor NFR") are excluded automatically — they never show up as something to reconcile or push

**Pushing**

- Quantity-only adjustments to existing contract lines. A brand-new line still requires typing in both cost and price by hand, with nothing pre-filled
- Every push goes through the same themed before-you-push confirmation the other invoice processors use, naming the exact client, contract, and current → new change before anything reaches Autotask
- Every status, error, and confirmation popup in this tool uses the Hub's own styled dialogs — never a plain browser popup
- Every push is written to the same shared activity log Cytracom, Kaseya, and BlackPoint already use, with a push history view in the tool itself

**Process each month's CSV within that month.** Like Cytracom, every adjustment is dated the 1st of the month you push in, not the month the file covers.

This tool is fully deterministic — there is no AI or AI-generated content anywhere in it.

**Access:** needs both a sidebar visibility toggle and a "Hub Role Matrix" row (tool key `duo-invoice-processor`), like any other tool.

## Under the Hood

- The "find the client's active contract that already carries this service" logic Cytracom uses was generalized during this build into a shared, vendor-neutral helper (`contractServiceSync.js`), so Duo reuses it rather than a third copy of the same lookup.
- Verified end-to-end against a real production push before release (Enscicon Corporation, Duo Essentials 20 → 22 seats).
