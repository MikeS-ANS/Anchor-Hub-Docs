# v3.9.0 — Payroll Review

**Released:** August 2026

## What's New

### Payroll Review (Beta)

The Hub's highest-sensitivity tool to date, replacing the standalone-HTML manual review process Mike previously ran in a separate Claude chat session before every payroll submission.

**File ingestion**

- Reads Heather's semi-monthly Paylocity export folder directly from SharePoint via Microsoft Graph — no more OneDrive sync-status guesswork
- A file checklist shows exactly what's present for the period, hard-stopping Parse until the required Comparison and Register files are there; optional supplemental files (Summary, New Hire, Termination) just get a soft note if missing
- The Comparison report is read whether Heather exports it as Excel or PDF — Paylocity has switched this format before and reverted mid-year at least once
- A `_V2` corrected file is detected and used automatically, cross-checked against the Register PDF for any employee whose numbers look stale

**Standing rules + flagging**

- A standing-rules engine, seeded from months of real payroll history, auto-clears known-safe recurring patterns before anything reaches a human
- Everything else is tiered — Action Required / Verify / Watch / Confirmed-Info — with dollar-amount judgment thresholds and prior-period carryover, so an already-open issue is referenced instead of re-raised from scratch
- A corrected re-upload merges against existing review state rather than wiping sign-offs and notes for unrelated flags

**Review workspace**

- Dashboard, Flags (with per-flag notes and one-click sign-off tied to your signed-in account), an Employees table, a pre-processing checklist ending in a final "OK to process payroll" gate, an isolated Audit Log, and a Standing Rules tab (manual add/edit/retire, plus approving or rejecting an AI-proposed rule)
- **Notify Puzzle — Approved to Submit** sends the real approval email via Microsoft Graph once the gate is checked, with an editable in-app preview first

**AI chat — the Hub's first tool-calling AI feature**

- A read-only chat scoped to the open review and full payroll history, built on a new generic tool-calling loop (`main/shared/hatzToolChat.js`) meant to be reused elsewhere — Timesheet Review is next
- Five on-demand tools: resolve a name (even just a first name) to an employee record, pull an employee's full pay history, pull flag history, look up standing rules, and get the current review's summary
- Strictly advisory — it can draft a standing-rule proposal as text for a human to approve, but there is no tool that lets it write anything directly

**Access**

Gated end-to-end — including every read — by a brand-new dedicated Azure AD role, `hub.payroll`, held only by Mike and Heather. This deliberately bypasses the Hub's general Role Matrix and excludes even `hub.admin`.
