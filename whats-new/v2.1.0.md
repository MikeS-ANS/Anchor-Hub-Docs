# v2.1.0 — Project Analysis Chart Overhaul

## Project Analysis

### Interactive Charts

The three canvas bar charts have been replaced with fully interactive tabbed horizontal bar charts. Each chart fills the card width and shows a hover tooltip with exact numbers and task details.

| Tab | What it shows |
|-----|---------------|
| **By Task** | Estimated vs. actual hours per task — two parallel bars per row |
| **By Resource** | Hours logged per team member with share percentage |
| **By Category** | Hours by billing code (from AT time entries; falls back to AI-inferred grouping) |
| **By Week** | Hours logged per calendar week across the project life |

### Over/Under Badges

Every task row in the **By Task** chart now shows an inline badge below the hours:

- **+Xh over** in red when actual hours exceed the estimate
- **−Xh under** in green when actual hours come in below

Overruns are immediately visible without having to compare bar lengths.

### By Week Timeline

A new **By Week** tab shows hours logged per calendar week from the first time entry to the last. Weeks with no activity are shown as dimmed rows with a dash — gaps in delivery are visible at a glance rather than silently missing from the chart.

High-activity weeks (more than 1.5× the project average) are highlighted in red.

### Export Improvements

The exported HTML report now includes all four charts (By Task, By Resource, By Category, By Week) plus the over/under badges. The light/dark mode toggle persists your preference per file via local storage.

Metric cards no longer have a maximum width cap — they stretch to fill the screen in full-screen mode.
