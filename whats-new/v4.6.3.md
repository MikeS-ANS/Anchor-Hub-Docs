# v4.6.3 — Setup fix for new computers

Released 21 September 2026.

**Nothing in Anchor Hub looks or works differently.** No new features, no changed screens, nothing to revisit in your settings. You don't need to do anything — the update installs itself the same way every other release does.

This one is about how the Hub gets onto a *brand-new* computer.

## What it fixes

Anchor Hub is meant to start on its own every time you sign in to Windows, and for anyone who has opened it at least once, it always has.

The gap was on machines that get set up automatically — a new starter's computer, provisioned in the background with nobody clicking through an installer. Because nothing ever opened the Hub on that machine, the step that says *"start this at login"* never ran. The Hub was sitting there, fully installed and perfectly fine, but it wouldn't have started by itself at that sign-in or any later one until somebody opened it by hand.

From this release on, the setup registers it directly. A newly provisioned computer now behaves exactly like one where somebody installed the Hub themselves: sign in, and the Hub is there.

## Does this affect you?

Almost certainly not. If the Hub already appears on its own when you sign in, nothing changes for you.

If you have a machine where the Hub is installed but never starts by itself, open it once from the Start Menu. That single launch is enough — it fixes itself permanently from then on.
