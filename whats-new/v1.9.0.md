# v1.9.0 — Company Directory Extension

## Overview

This release extends the Hub Company Directory with four new per-company attributes — MSC workbook name, CIPP tenant domain, Google Workspace flag, and SharePoint folder — and adds two new matching tabs to Company Mapping so those fields can be populated quickly and accurately.

---

### MSC Clients Matching Tab

A new **MSC Clients** tab in Company Mapping reads all companies from the MSC workbook and matches them to AT companies using the same fuzzy-matching engine as Meraki Orgs.

- **Auto-Match** scores all unmatched MSC companies against AT companies and shows confidence badges (High / Med / Low)
- **Accept All High** accepts every match at ≥ 0.75 confidence in one click
- Individual rows can be accepted, skipped, or manually assigned via an inline search dropdown
- The matched name is stored as `mscName` in the hub directory and serves as the join key for MSC workbook data in the User Audit Report

---

### CIPP Tenants Matching Tab

A new **CIPP Tenants** tab fetches all tenants from the CIPP API and lets you link each one to an AT company.

- Uses OAuth 2.0 client credentials — credentials stored in Azure Key Vault (`cipp-tenant-id`, `cipp-client-id`, `cipp-client-secret`)
- Matched tenant domain is stored as `cippDomain` on the hub company entry
- Same confidence-badge and Accept All High workflow as other matching tabs

---

### New Company Attributes

Each hub company now carries four additional fields, editable inline from the Companies tab:

| Field | Description |
|---|---|
| `mscName` | MSC workbook join key — set via MSC Clients matching tab; clearable with × |
| `cippDomain` | CIPP tenant domain override — editable inline or via CIPP Tenants tab |
| `googleWorkspace` | Toggle: **Off** / **GWS** — marks Google Workspace clients to skip M365 audit steps |
| `sharepointFolder` | Per-client SharePoint folder path for audit report delivery |

---

### clients.csv Bulk Import

An **Import clients.csv** button in the Companies tab header bulk-populates the four new fields from a structured CSV. This was used to pre-populate data from the existing POC dataset without manual entry. The import matches by AT company name (exact, then fuzzy ≥ 0.6) and skips rows with no match.

---

### Bug Fixes

- **ECONNRESET on MSC file downloads** — SharePoint pre-authenticated download URLs would drop the connection partway through when using `node-fetch`. Downloads now use Electron's `net` module (Chromium network stack), which handles these connections reliably. The same fix was applied to the Kaseya revenue data download.
