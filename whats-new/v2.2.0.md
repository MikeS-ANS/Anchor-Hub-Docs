# v2.2.0 — Invoice Processor Overhaul, PTS Improvements

## Invoice Processor

### Company mapping now uses the Company Directory
The invoice processor previously read company mappings from a local file that was not kept in sync with the Company Directory. Companies you linked in the Company Directory would still show as "no match" when processing an invoice.

All mapping reads and writes now go through the SharePoint hub directory — the same source as the Company Directory. Mappings confirmed in either place are immediately recognised by both tools.

### SharePoint invoice cache
The first time you process an invoice via the API, the raw line items are saved to SharePoint. The next time anyone on the team opens the same invoice, it loads from cache instantly — no Pax8 API call, near-instant results.

A banner at the top of the results shows when the data was last fetched. Use the **↺ Reprocess** button to force a fresh pull from Pax8 (e.g. if you want to pick up a recently added company mapping for an older invoice).

Company mapping resolution always runs fresh against the current hub directory — so changes in the Company Directory are always reflected without reprocessing.

> CSV uploads are not cached (the filename is not a stable key).

### Auto-match accuracy improvement
The auto-match feature searches Autotask by company name. Previously it used the first word of the Pax8 name regardless of how generic it was — words like "Solutions", "Technologies", or "Services" would match hundreds of AT companies and produce false high-confidence saves.

The search now skips generic stop words and uses the first distinctive word instead, significantly improving match quality.

### Invoice picker cleaned up
The month/year dropdown no longer shows a dollar amount next to each invoice. The amount shown was Pax8's "Total Due" — which on Net 45 payment terms includes the previous month's unpaid balance, not just the current month's charges. The correct partner cost total appears in the results after processing.

### One-Time Charges table
The One-Time Charges section now expands to full page width so all 8 columns are visible without horizontal scrolling.

### Bug fixes
- Service Quantities push buttons (Nerdio, Exclaimer, Ironscales, Printix) were duplicating on every re-render — fixed.
- Removed Azure and O365 from the metric strip — those amounts are subsets of Total Partner Cost and are already shown in the QBO breakdown table directly below.

## Project Time Summary

### 90-day week-over-week history
Δ Week (week-over-week change) now compares against daily snapshots going back 90 days, up from 30. Older snapshots are pruned automatically on each run.

### Collapsible settings sections
All four settings panels are now collapsed by default:

- Email Settings
- Always Exclude Projects
- Project Filters
- Auto-Send Schedule

Click any panel header to expand it. Your saved settings are unchanged.

---

## Home Screen

The Autotask Tickets widget has been removed from the home screen. It was not fetching data correctly and will be restored in a future release once the underlying connection is stable.
