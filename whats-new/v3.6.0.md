# v3.6.0 — Client Touch Aging Report

## New

**Client Touch Aging Report** — flags MSC MRR+ORR clients whose Autotask CompanyNotes touches have gone stale: no Note/Quick Note in 3 months, or no Client Meeting in 12 months (both admin-editable). A new **due-soon early-warning tier** also flags clients approaching — not yet past — a threshold, so the list is broader than just outright breaches.

- **Table / Cards / By Account Manager** views (your choice is remembered), with a My clients / All clients scope toggle and search + AM filter
- **Priority score** — every flagged client is weighted by contract renewal proximity, active contract value, and recent Autotask ticket volume, and the list now sorts by "highest priority first" instead of just staleness. Sortable as its own column in Table view, shown as a ★ badge with 📅/💰/🎫 signal icons everywhere else
- **Log a touch** — a "+ Log touch" button on any row posts a real Autotask CompanyNotes entry directly from the Hub (requires your personal Autotask API key, same requirement as User Audit Report's write-back), reflected in the report immediately
- **Scheduled digest** with recipients/cadence settings and a preview/send-now modal, mirroring User Audit Report's billing digest
- Admin-only settings (thresholds, touch types, excluded clients, sync time) enforced server-side; digest settings are open to any signed-in user

Data is cached in Azure SQL via a daily sync (plus a manual "Check for new data" button) — this tool never queries Autotask live at view time, to stay well under Autotask's API rate limits.

Marked **Beta** in the sidebar while two open questions get confirmed with the requester: whether staff have actually been logging touches under a stray "Notes" (plural) Autotask action type included defensively in the default bucket, and whether the priority score's ticket-volume weighting (more tickets = higher priority) holds up against real usage.

No AI/LLM component — purely deterministic threshold logic and weighting.

See the [Client Touch Aging Report guide](../tool-guides/client-touch-aging.md) for the full breakdown, and [Roadmap](../getting-started/roadmap.md) for where this sits alongside the rest of the Hub.
