# v3.8.0 — Cytracom Invoice Processor

**Released:** August 2026

## What's New

### Cytracom Invoice Processor

A new tool in the invoice-processor family, alongside Pax8, Kaseya and BlackPoint. Cytracom is ANS's VoIP and network vendor (product line "ControlOne"). Unlike Pax8 there's no API into Cytracom, so invoices arrive as PDFs — this tool reads that PDF, breaks it down per client per service, and compares each quantity against what's actually provisioned on that client's Autotask contract.

**Loading an invoice**

- Drag and drop a PDF, browse for one, or pick a previously-archived file straight from SharePoint (`ANSVendors/Cytracom/{year}`)
- The picker shows each file's **real invoice month** — read from inside the PDF, not guessed from the filename — along with its invoice number and a ✓ if it has already been pushed
- Newest first, with the newest unprocessed invoice pre-selected
- A locally-supplied file can be archived to SharePoint on the way through

**Reviewing**

- Per-client, per-service diff table: invoice quantity vs. current Autotask quantity, the difference, cost and price
- Client sections sort alphabetically, with ANS's own internal usage always last — that section is shown so the invoice total still makes sense, but is never reconciled against a contract and can never be pushed
- A client with no Cytracom mapping yet can be matched **inline, from this screen** — search for the Autotask company and confirm; the Cytracom name is taken from the invoice, so there's nothing to type by hand
- "No contract yet" and "contract state unknown" are kept clearly separate — an unknown result never reads as "there isn't one"
- Line items with no matching Autotask service are flagged and can be added to the catalog inline, without blocking the rest of the invoice from being reviewed

**Pushing**

- Quantity-only adjustments on existing lines. Price and cost on an established contract line are **never** touched — the Cytracom invoice only shows Cytracom's wholesale cost to ANS, never ANS's retail price to the client
- Brand-new lines require you to type both cost and price, with no pre-filled default of any kind. A zero or negative value needs an explicit tick to confirm it's intentional
- Every push goes through a confirmation naming each client, service, target contract, and the exact current → new change before anything reaches Autotask
- Every push is written to the shared activity log, with a push history view in the tool

**Repeat invoices**

Processed invoices are tracked by Cytracom's own invoice number parsed from the PDF, not by filename or month — a mid-cycle prorated invoice can arrive as its own PDF in the same month as the regular one. Re-opening an invoice that has already been pushed warns you, but doesn't block it, so a partially-failed push can still be retried.

**Process each month's invoice within that month.** Every adjustment is dated the 1st of the month you push in, not the month the invoice covers. Processing promptly keeps those the same.

This tool is fully deterministic — there is no AI or AI-generated content anywhere in it.

**Access:** needs both a sidebar visibility toggle and a "Hub Role Matrix" row, like any other tool.

## Under the Hood

- The contract and service reconciliation logic that the Kaseya Invoice Processor has used for a long time was extracted into a shared module both tools now call, so a future fix to it benefits both instead of drifting into two copies. Kaseya's behaviour is unchanged.
- Cytracom was added as a mapped platform in the Hub Company Directory, with its own column alongside Pax8, Kaseya, BlackPoint and Meraki.
