# v3.11.1 — User Audit Report Improvements & Beta Graduations

**Released:** August 2026

## What's New

### User Audit Report

**More reliable matching**

- Matching an Autotask contact to their Microsoft 365 account now checks all three email fields Autotask can store on a contact, not just the primary one — so a contact whose real login ended up in a secondary email slot (say, after a domain change or a typo in the primary field) is still matched correctly instead of showing up as "missing from Autotask."

**"Full Support" replaces "Active" in History**

- The History tab's "Active" column is now **Full Support** — the same classification already used everywhere else in the tool to judge contract compliance. Older history entries recorded before this change will show a dash for this column rather than an incorrect retroactive number.

**Account Manager Dashboard — Included / Full Support / Over-Under**

- Three new columns appear next to every client on the AM Dashboard, across all four sections (Needs an audit run, Pending, Overdue, Good standing):
  - **Included** — the contracted seat count from the MSC workbook
  - **Full Support** — the client's current full-support user count
  - **Over/Under** — the difference between the two, color-coded so a client that's drifted from its contract stands out at a glance
- This means an Account Manager can spot a client that needs attention without opening the separate Contract Review tab.

**Contract Review — renamed for consistency**

- The "Delta" column (and related wording elsewhere on the tab) is now **Over/Under**, matching the new AM Dashboard column and the History tab.

### Beta tags removed

- **Client Touch Aging** and **Block Hour Report** have both been in active daily use long enough to graduate out of Beta — the sidebar, page title, and in-app Help listing no longer show the Beta badge for either.
- Timesheet Review and Payroll Review remain marked Beta while feedback is still being gathered on those.
