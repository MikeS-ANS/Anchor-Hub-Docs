# v3.2.0 — Timesheet Review Tool (Beta)

A manager-facing tool for reviewing a resource's or team's Autotask time entries — client-facing utilization %, deterministic data-quality flags, and an AI review that narrates pre-computed severity instead of judging it fresh each time.

## What's new

- **Timesheet Review**, marked **Beta** in the sidebar and in the tool itself while we gather feedback from managers before a general release. See the full [Timesheet Review guide](../tool-guides/timesheet-review.md).
- Client-facing utilization % against a configurable target, plus six deterministic flags — Gap, Overlap, Late Entry, Thin Note, After Hours, and Note/Duration Mismatch — all with admin-configurable thresholds.
- An AI Addendum layer tiers each flag type's recurrence (CONCERN/WATCH/NORMAL) using fixed, settings-driven thresholds computed once per scan. Manager Review, Team Review, and Ask AI all narrate those same tiers instead of each independently deciding what counts as a real pattern — so results stay consistent no matter which of the three you use. A fully normal period visibly restyles its "Review with AI" button instead of running a model call to say nothing happened.
- Team scoping via Microsoft Graph direct reports, with `hub.admin` seeing every active resource. Results cache in Azure SQL, so reopening a period you've already scanned is instant — Refresh forces a live re-pull.
- Deep links out to Autotask for actual timesheet approval — there's no in-Hub approval step (Autotask's API has no such endpoint).

## Why Beta

The deterministic checks and AI tiering are new enough that we want managers actually using it against real timesheets before calling it done — particularly the note/duration mismatch keyword table, which is seeded with a best guess pending real note phrasing from the service desk team, and the pattern-tiering rate thresholds, which haven't been tuned against a full review cycle yet. Expect both to be adjusted based on what comes back from this Beta period.

## Also in this release

- Fixed an off-by-one bug in the AI Note Review month-range cap that could reject a plain single-calendar-month period for users in negative-UTC timezones (e.g. Denver).
- Azure App Configuration reads now cache briefly and settings saves write sequentially instead of all at once — fixes a throttling issue that could make a Settings save hang for minutes.
- Inline gap-duration indicators on the day view, color-tiered green/yellow/red by how long the gap is.
