# v4.6.2 — Pax8 Invoice Processor hardening

A hardening pass on the **Pax8 Invoice Processor**. No new tool, and the monthly workflow is unchanged — this fixes the parts that could quietly go wrong.

## The three that matter

### You now see every number before it's written

The push confirmation used to say "Push 34 Companies" and a date. It now reads Autotask first and shows, per client, the exact contract and service line being written to, the current value, the new value, and the change.

It calls out separately:

- rows writing a **zero**
- rows with a **fractional quantity**
- rows that will be **skipped** — already correct, not mapped, or no matching contract
- rows whose Autotask lookup **failed** (not the same as "nothing to change")
- rows the push will **refuse**, because two Pax8 accounts point at one Autotask company

Zeros are shown, never blocked — zeroing a price is a legitimate monthly step.

Reading those values can take up to a minute. The Push button stays disabled until they arrive, and if they can't be read the panel says so rather than showing an empty table.

### A failed download can no longer become a real dollar figure

If a page of the invoice failed to load, the tool used to carry on and report success with roughly a third of the real total — then write that wrong number into the shared cache, where it stuck until someone reprocessed.

It now retries, and fails loudly if it can't finish.

> **Worth knowing:** this fix is shared with **Margin Analyzer** and **Invoice Monitor**, which were silently truncating the same way. If either starts showing errors it didn't before, that's the fix working — it was hiding them.

### Company matching no longer guesses on your behalf

It used to save any match scoring 85% or better straight into the shared Company Directory. The scorer strips words like "Group", "Technologies" and "Solutions" before comparing, so "Anchor Group" scored 97% against "Anchor Technologies" — different companies.

Every match is now a **suggestion**, and nothing is saved until you click **Confirm**. A lookup that *failed* is listed separately from "no match found", so a timeout no longer looks like an answer.

## Also fixed

- A genuine **$0.00** line books zero instead of falling through to cost × quantity
- Azure and service rows group by Pax8 **company ID**, not display name — two clients sharing a name no longer merge into one row
- Contract lookup respects the **end date**; an expired contract with a later start date used to win
- Azure **skips rows that aren't changing** instead of writing an adjustment every month regardless
- The QuickBooks breakdown no longer **hides a negative category** it still counts in the total
- A one-time line is only billed as a product when it's an **Arrears Charge** — closing a setup-fee hole without touching how Nerdio, Printix and Ironscales are actually billed
- The confirmation **can't be dismissed mid-push** by a stray click outside it
- A failed write to Push History is **reported**, instead of leaving Autotask updated with no record
- Quantity pushes are **verified by reading the value back**, as Azure already was
- Push History says so when it **can't be loaded**, rather than showing "Never pushed"
- Pax8, Kaseya and Cytracom data is **cleared when you sign out**

## New — the tool has its own Settings tab

Alongside **Invoice** at the top. It holds the **default Azure margin**, previously fixed at 20% in the code so changing it needed a new release.

It's stored centrally, so it's the same number for everyone. Saving needs the Hub admin role. A blank or out-of-range value is refused and the current value kept — it never silently becomes zero.

Per-row margin and price overrides are unchanged; this only sets where each row starts.

## Removed

- **Browse CSV** — the tool loads from the Pax8 API only
- The **prompt-template** settings, which nothing had ever used
