# v3.2.1 — Timesheet Review: team scoping fix

Quick patch fixing a permissions bug found while managers were testing the v3.2.0 Beta.

## Fix

Non-admin managers got a `403 Insufficient privileges` error opening Timesheet Review. `/me/directReports` returns *other users'* data (it's a navigation property, not your own profile), so it needs the `User.ReadBasic.All` Graph permission — plain `User.Read` doesn't cover it despite the "/me" prefix. The original assumption that `User.Read` was sufficient had only ever been validated against a Global Admin account, which reads directory data through a different path regardless of the app's actual granted scope.

**If you use Timesheet Review as a manager (not `hub.admin`), sign out and sign back in once after updating** to pick up the newly-consented permission. You may see a one-time consent prompt depending on your account.

No other changes in this release. See [Timesheet Review guide](../tool-guides/timesheet-review.md).
