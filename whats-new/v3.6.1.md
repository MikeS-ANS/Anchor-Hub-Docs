# v3.6.1 — Duo Management access fix

## Fixed

**Duo Management** was checking access against two roles (`hub.it` and `hub.standard`) that were retired when the Hub Role Matrix moved to its current role set. The sidebar already knew about the new roles, so some staff could see Duo Management listed but got a "you need the hub.it or hub.standard role" message when they opened it.

Duo Management now checks the same roles the sidebar already uses (Admin, Manager, Delivery, Tam, Strategic), and everyone with access to the tool now sees all of its tabs rather than a limited subset.

See [Roles & Permissions](../getting-started/roles-and-permissions.md) for how tool access is currently assigned.
