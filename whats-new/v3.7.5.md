# v3.7.5 — Client Touch Aging: Technologist & TAM columns/filters

## New

**Technologist & TAM columns and filters** — Client Touch Aging's Table and Cards views now show two additional columns, **Technologist** and **TAM** (Technical Account Manager), alongside the existing Account Manager info. Both are sourced from Autotask's **Associations → Account Team** (the `CompanyTeams` entity), joined against each team member's `Resource.title` — a different Autotask concept from the Account Manager/Owner field used everywhere else in the report, so don't assume the two always point to the same person.

Each column gets its own filter dropdown, populated from whoever is currently assigned to a flagged client — the same interaction pattern as the existing Account Manager filter.

Because Account Team job titles are free text in Autotask rather than a fixed picklist, which titles count as "Technologist" vs. "TAM" is controlled by a new admin-only **Account Team Roles** section in Settings, not hardcoded. Defaults are `Technology Strategist` and `Director of Client Success` for Technologist, and `Technical Account Manager` for TAM — matching is case-insensitive substring, so e.g. "Senior Technical Account Manager" still counts.

See [Client Touch Aging → Technologist & TAM columns and filters](../tool-guides/client-touch-aging.md#technologist--tam-columns-and-filters) for the full writeup.

## Fixed

**Table view no longer clips the Breach column** at narrower window widths (past roughly 921px) — a table-layout overflow issue that could cut off the right edge of the report is now handled correctly.
