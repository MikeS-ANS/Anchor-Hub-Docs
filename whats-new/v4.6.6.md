# v4.6.6 — Settings clean-up, part 1

Released 22 September 2026.

The **Settings** page was built before tools had settings of their own, so it's being cleaned up one section at a time. This release handles three sections: two are moved into the tools they belong to, and one is removed because it's no longer needed.

## MSC Agreements reads the real workbook, for everyone

MSC Agreements used to need a file location typed into Settings → General. In practice that location was set on only one computer, and it pointed at an old one-tab copy of the MSC workbook that had fallen out of date. Everyone else saw "No file configured," and Contract Renewals quietly showed no agreement rates.

The tool now reads the **Agreements** tab of the shared MSC workbook on SharePoint directly. There's nothing to set up.

- **Editing still works, and it saves straight into the shared workbook.** You can change Month, Year Signed, TC Increase, S+ Increase and Industry, then click **Save to MSC Sheet**.
- **Company, Users, Monthly MSA and Lifetime Value are greyed out.** They're formulas that pull from the Revenue tab, so change them there. **Open MSC Sheet** opens the workbook in your browser.
- **Nothing gets overwritten by accident.** Before each change is saved, the Hub checks that nobody changed that cell in Excel since you loaded the page. It also checks the cell after saving to confirm the change stuck. If a change is skipped, you're told which one and why.

## Pax8 → PSA Mappings is gone

This section only reported on two old mapping files that nobody uses any more. **Company Mapping** is now the only place Pax8 clients and products are matched to Autotask.

One behaviour changes because of this. Sometimes the Company Directory can't be loaded, for example during a network problem. In that case **Subscription Audit** and **Margin Analyzer** now stop with the message *"Could not load the Company Directory… Nothing was checked."* Before, they could carry on as if no mappings existed. That could make an audit look like it succeeded while checking nothing, and in rare cases it could even open wrong "Service Missing from PSA" tickets. Now no tickets are created; wait a minute and run it again.

## Contract Renewals' eligible-services list moved into the tool

The list of services eligible for a % price increase now lives in the tool's own **⚙ Settings** window instead of Settings → General.

- **It's shared by everyone, and only Hub admins can change it.** Everyone else sees it read-only.
- **It can't be overwritten with defaults.** If the shared settings store can't be reached, the window shows the built-in list with a warning, and Save stays off until the store is back.
- **What the list actually does:** services whose names match are marked **✦ eligible**. Those are the services **Apply Rates** updates using the client's MSC agreement increase.
- **The "Comparison Prompt Template" field is gone.** It never did anything; **Compare All with Claude** has always used its own built-in prompt.
