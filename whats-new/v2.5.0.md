# v2.5.0 — Values & Norms

A new daily touchpoint that brings ANS's 5 Core Values and 22 Cultural Norms — previously only in Strety and the printed pamphlet — into the Hub itself.

## Home screen widget

A widget above Quick Links features one Value or Norm each day, the same for everyone on the same date. It shows the item's type (Value/Norm badge), title, and a short AI-generated blurb that applies the item to a real-world MSP scenario — generated once per day and shared across the whole team, not regenerated per person.

- **Surprise Me 🎲** shows a different random item on demand (never the daily item, never the AI text — just its short description). It resets back to today's item next time you open the Hub.
- **View All →**, or clicking anywhere else on the widget, opens the full library.

## Values & Norms library

A new sidebar entry ("Values & Norms") opens a searchable card grid of all 27 items. Filter by All / Values / Norms, search by title or description, and click any card to flip it and read the full definition. Today's featured item is highlighted with a "Today" chip.

Content lives in a "Hub Values & Norms" SharePoint list — admins can hit **Refresh** in the library header after editing content there to pull the latest version immediately instead of waiting for the daily cache to expire.

See the [Values & Norms guide](../tool-guides/values-norms.md) for details.
