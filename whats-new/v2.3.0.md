# v2.3.0 — User Audit Report

A new tool that replaces the manual, every-other-month user audit. It joins Autotask contacts with **live Microsoft 365 data (via CIPP)** to catch users who are licensed in M365 but missing from Autotask — the people you may not be billing for — then manages the whole review-and-bill-back cycle.

See the full [User Audit Report guide](../tool-guides/user-audit-report.md).

## Generate
- Build **Full**, **Client-facing**, or **Both** Excel workbooks with real drop-downs, a hidden baseline for automatic change-highlighting, the M365-only "gap" section, and an internal summary.
- Saved to the client's **ANS-Clients** SharePoint folder; type-to-filter client picker; multi-recipient client email using an action-oriented template that attaches the current SharePoint copy.
- Google Workspace clients skip M365; runs with no M365 data are clearly flagged.

## Write-back
- Auto-loads the client's returned workbook from SharePoint (or manual upload, pushed back).
- Previews only the changed rows, updates the Support Classification, deactivates/reactivates contacts appropriately, and can create Autotask contacts for M365-only users (de-duplicated by email).
- Posts an account note summarizing confirmed vs. contracted users.

## Account Manager Dashboard
- Role-gated lifecycle view: needs-a-run, sent-pending, sent-overdue (with Start Write-Back), and good-standing — filtered to your own clients by default.
- **Add Time** button logs a quick entry (Client Success work type) to each client's time-tracking task.

## User Count Contract Review
- Finance/admin roll-up of contracted vs. supported users, PROVISIONAL/CONFIRMED basis, and a dollarized overage using the MSC Seat Price.
- Out-of-compliance clients first; per-client dispositions and notes; a billing digest you can preview, send now, or schedule weekly/monthly.
- Records decisions and posts notes only — it never changes Autotask contract quantities automatically.

## Company Directory
- New per-client fields: MSC name, CIPP domain, Google Workspace flag, SharePoint folder, and time-tracking project/task linkage (auto-match + re-sync).
