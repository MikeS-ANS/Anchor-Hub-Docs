# v3.6.2 — Company Directory Rebuild

## New

Company-to-platform mapping (Kaseya, Blackpoint, Meraki, MSC, CIPP, Pax8) is consolidated onto one shared "search Autotask, click to attach" popover, replacing four separate bespoke search-and-attach flows that had grown apart over time.

- **Companies tab** is now the canonical mapping surface — sortable by Autotask Company or Status, a sticky company-name column that stays visible while scrolling, inline Autotask classification, clickable company names linking straight to Autotask, and the shared attach/reassign/remove flow now covers every platform plus MSC Name, CIPP Domain, Google Workspace, and SharePoint Folder
- **Auto-provisioning** — a new identity sync keeps the directory current with Autotask automatically (admin-configurable filter settings, nightly + a manual "Sync Now"), plus a manual **+ Add Company** for anything outside the filter
- **Meraki Orgs / MSC Clients / CIPP Tenants / Blackpoint Confirm Match** all use the same shared attach popover now, with a fuzzy name-match hint on MSC/CIPP when there's no exact Autotask match
- **Time Projects** tab now shows Autotask classification, the linked project's start/end dates with a past-end-date flag, and a per-client exclude toggle
- **Kaseya Invoice Processor** gained a prominent "→ Org Mapping" shortcut

## Fixed

- Confirming a match in Kaseya Org Mapping could silently write a corrupt entry into that company's Pax8 mapping — a leftover click-handling conflict between two screens that used to share the same interaction pattern. Gone now that both use their own dedicated component.
- Pax8 Sync's review list was showing "undefined" instead of company names, and clicking Accept wasn't actually saving the match — a pre-existing bug (unrelated to the rebuild above) caught during testing for this release. If you accepted any Pax8 matches recently, it's worth double-checking they actually stuck.

See the [Company Mapping guide](../tool-guides/company-mapping.md) for the full rundown, and [Roadmap](../getting-started/roadmap.md) for where this sits alongside everything else.
