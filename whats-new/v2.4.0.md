# v2.4.0 — Hub Directory Migration, Scheduler Fix & Billing Accuracy

A maintenance-focused release: the Company Directory is now the single source of truth everywhere, a silent Meraki scheduler bug is fixed, and several billing/reporting numbers were corrected to reflect what they claim to show.

## Fixes

**Hub Directory migration**
Margin Analyzer, Subscription Audit, CSV mappings, and Company Mapping all read exclusions and client/service mappings from the Company Directory now — the legacy local `pax8hub-mappings.json` cache file is retired. This means changes made in Company Directory take effect everywhere immediately, with no separate local file to fall out of sync.

**Meraki scheduler**
Fixed a bug where the weekly Meraki License & EoL scan silently failed to schedule at all — no error, no log line, it just never ran. The schedule and expiration threshold are now shared settings (SharePoint), not per-user, since the scan's results are shared too.

**Kaseya settings save**
Fixed the Workplace Bundle Overrides setting failing to save in the packaged app (`ENOENT` — wrong file path pointed inside the read-only app bundle).

**Pax8 Invoice Comparison**
The AI summary and Total Amount metric card were using the invoice's Total Due, which includes carryover balance from prior months under our Net 45 terms — overstating the current month's actual spend. Both now use the sum of current-period line items instead.

**Project Analysis — billing type**
Billing type is now read from the contract name's `-FF`/`-TM` suffix instead of the raw Autotask contract type, since some T&M-style engagements are billed through Fixed Price contracts to use milestones. When no suffix is present, the report visibly flags the billing type as inferred rather than guessing silently.

**Project Analysis — model selection**
Your Hatz AI model choice is now saved the moment you change it, instead of only after a completed run — so it no longer resets to "Auto" if you pick a model and reopen the tool without running an analysis.

## New Features

**Subscription Audit caching**
The Pax8 subscription list is now cached to SharePoint per billing month — a cache banner shows whether a run loaded from cache or fetched live, with a **Refresh** button to force a live re-fetch.

**Project Analysis — Custom Instructions**
An optional field lets you steer a specific analysis run (e.g. weigh public effort-estimate data before concluding a project was under-scoped) without touching the default prompt. It's appended, not a replacement, and shown in the report so anyone reading it later knows the analysis was steered.

**Project Analysis — week breakdown**
Hovering a week in the By Week chart now shows an hours breakdown by category and by resource, not just a total — so a "fully worked" week that turns out to be 100% project management is visible. The same breakdown is included in the exported report.
