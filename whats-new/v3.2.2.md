# v3.2.2 — Bug fix batch + Ideas/Bugs export + sidebar export/import

## Bug fixes

- **User Audit Report**: fixed "Included Users"/"Last Audit Ran" header overlap under the Generate tab.
- **Taskbar icon**: fixed pinning the Hub showing 2 icons instead of sticking to the pinned one — a mismatch between the app's Windows identity and the installer shortcut's. If you already pinned the app, unpin and re-pin once after updating to pick this up.
- **Announcements**: dismissing one now persists across restarts (it used to reset every time you reopened the app). Also added a second announcement type that can't be dismissed at all, for things that should always show until someone edits or expires them.
- **Sidebar section collapse**: collapsing a group in the sidebar now persists across restarts — it used to reset every launch.
- **Settings — AI Prompt tab removed**: it only ever held one field (Contract Renewals' comparison prompt), presented as if it were a global, multi-tool setting. Moved into Contract Renewals' own in-tool Settings modal.
- **HR benefit cards / Home calendar**: long portal URLs and meeting links no longer overflow past the card or row edge — they truncate with an ellipsis now (hover to see the full value).
- **Contract Changes**: the Changed By / Change Type / Actor filter dropdowns no longer render behind — and clickable through — the summary strip below them. Same root cause as an earlier Ideas & Bug Tracker fix (a global CSS rule that ties every direct child of the main content area to the same stacking layer); every other tool was audited for the same pattern and none were affected.

## New

- **Settings now opens to the Customize tab** by default instead of General — sidebar customization is what most people actually touch first.
- **Ideas & Bug Tracker: Markdown export.** Select 1 to all items via checkboxes and export a single Markdown file with each item's status, description, attachments (as links), and full comment thread. See the [Ideas & Bug Tracker guide](../tool-guides/ideas-bug-tracker.md).
- **Sidebar customizations export/import.** Your sidebar layout and personal quick links live on your machine only, not tied to your Microsoft login — reinstalling or moving to a new computer used to lose them. Settings → Customize → **Export** saves both to a file; **Import** on the new machine brings them back in one step. See [Configuring Your Settings](../getting-started/configuring-settings.md#sidebar-customization-export--import).

See [Roadmap](../getting-started/roadmap.md) for where this sits alongside the rest of the Hub.
