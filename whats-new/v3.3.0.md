# v3.3.0 — Ideas & Bug Tracker improvements + fixes

## Ideas & Bug Tracker

- **Sort dropdown** replaces the old Priority/Newest toggle button — now also sorts by Status, Alphabetical, or Created By.
- **Closed section**: terminal-status items (Shipped/Declined/Duplicate for ideas; Fixed/Won't Fix/Duplicate for bugs) collapse into their own "Closed" section by default instead of cluttering the main list.
- **Per-user hide**: hide any item from your own view via the eye-slash icon on each row — this is local to your machine only, not synced across devices or visible to the team. A "Hidden" section lets you bring items back.

See the [Ideas & Bug Tracker guide](../tool-guides/ideas-bug-tracker.md) for the full rundown.

## Fixes

- **Spell check**: right-clicking a misspelled word (anywhere text input is used, including the Ideas & Bug Tracker's submit modal) now shows dictionary suggestions and an "Add to Dictionary" option. The red underline always worked — Chromium detects misspellings on its own — but Electron doesn't wire up a suggestions menu without being told to, so right-clicking previously did nothing.
- **Help page**: the Tools Overview grid was silently missing 8 already-shipped tools — Project Analysis, Meraki Admin Management, Meraki License & EoL Expiration Report, User Audit Report, Timesheet Review, HR & Resources Portal, Values & Norms, and Ideas & Bug Tracker itself. All added back.
- **User Audit Report**: if a data source fails to load (most commonly: you don't have SharePoint permission to the MSC workbook), the Account Manager Dashboard and Generate tab now show a clear warning banner naming exactly what failed and why, instead of silently rendering an empty list that looked identical to "you just don't own any clients."

See [Roadmap](../getting-started/roadmap.md) for where this sits alongside the rest of the Hub.
