# v3.1.0 — Ideas & Bug Tracker

A new pinned tool for submitting, voting on, and tracking ideas and bug reports — replacing the old "Report a Bug" button, which just sent an email with no visibility into what happened next.

## What's new

- **Ideas & Bugs**, pinned in the sidebar between Help and Settings, visible to everyone. See the full [Ideas & Bug Tracker guide](../tool-guides/ideas-bug-tracker.md).
- Submit, vote on, and comment on ideas and bugs; watch their status move through a real lifecycle instead of disappearing into an inbox.
- A notifications bell surfaces updates on anything you're following.
- Hub Admins can change status, post Official comments, merge duplicate reports together, and delete items outright.

## Why this matters

This is the first Hub feature built entirely against the Sprint 2 Azure SQL + Functions backend from a blank slate — not a migration of something that already existed on SharePoint. It validates that pattern (Electron → Functions → SQL) end to end for whatever gets built next on top of it.

It's also the first feature to go through a new step in how the Hub gets built: a design pass with Claude Design produced high-fidelity mockups before any code was written, which is why this tool looks and feels consistent with the rest of the Hub's dark theme and components on day one.

See [Roadmap](../getting-started/roadmap.md) for where this sits alongside the rest of Sprint 2.
