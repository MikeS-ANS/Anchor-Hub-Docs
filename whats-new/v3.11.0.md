# v3.11.0 — User Increase Automation

**Released:** August 2026

## What's New

### User Increase Automation

A guided 3-step flow added to **User Audit Report**'s existing Contract Review tab, replacing the fully manual process an Account Manager previously ran across three separate systems every time a client grew past its contracted user count.

**① Update Calculator**

- Opens the client's real "{Client} Service Plan Calculator.xlsx" in SharePoint via a saved, self-healing link — if the file gets moved or renamed, the Hub re-finds it by name pattern rather than failing
- The Hub never reads the calculator file itself — you set the new user count there, then type the resulting price and cost back into the Hub
- A sanity check compares your new total against the *expected* current total (today's per-seat rate × contracted count) and warns before continuing if it looks like a large jump

**② Update Autotask**

- Pushes the new invoice description, price, and cost to the matched contract service line
- Posts a real Autotask **Contract Note** — the same "Contract Notes" tab your own manual "+N users" notes have always lived on, not a company-level note
- Effective date defaults to the 1st of next month, always editable if you need to push it out further
- If either half fails, it's shown separately with its own retry — nothing silently half-completes

**③ Update MSC Sheet**

- Runs automatically once Step ② succeeds — no separate click
- Updates the Included Users count and adds a dated note to the Contract Notes column, newest note first
- Edits the live file directly (the same underlying mechanism Excel Online's own real-time co-authoring uses), so it doesn't conflict with anyone else who has the workbook open at the same time

### Contract Review tab improvements

- Each row's action button now reflects real progress — "Increase," "Continue (Step 2 of 3)," "Continue (Step 3 of 3)" — with a small progress indicator, instead of a plain "Increase" that looked the same whether a client had never been touched or was already halfway through
- A real filter: **All clients**, **Confirmed positives**, or **Provisional positives** (a look-ahead at what's likely coming once those clients confirm)
- New **Increase History** view — every client that's gone through the flow, across every review cycle, with a way to remove stale test entries
- The Disposition option list no longer includes "Increase contract" as if it were an action on its own — that's what the Increase button does now. The remaining options (No change, Waive, Needs follow-up) are for clients you're deliberately *not* increasing this cycle
- The billing digest email now only counts clients whose write-back has been confirmed, not provisional ones — so the number in the email matches what's actually actionable
